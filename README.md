# Master_Thesis_Code

## Model provenance and attribution

The OpenMC HTGR model used as the starting point for this work was
originally developed as part of a summer student project at the
University of Oslo by Elise Harila Christensen, Ella Hedegart Flaata,
Baltasar Johannes Hemmerle and Hannah Westgaard, supervised by Ole Reistad.

The original report and reactor model were shared directly with
Herman Holum by Baltasar Johannes Hemmerle. The file
`homogen_reactor_model.py` contains geometry, material definitions and
other model elements derived or adapted from this original work.

The present repository extends the original model through depletion calculations,
post-processing, source-term modelling and consequence analysis.
